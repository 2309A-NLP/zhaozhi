# gd4 rag_qa_system 测试文档

## 测试目标
验证 gd4 的复杂 PDF 解析增强是否真正可用，并确认多模式不会互相干扰。

## 测试维度
- 基础接口测试：健康检查、文件列表、统计、问答、路径导入、文件导入
- 模式测试：`local`、`hybrid`、`auto`、`vision_hybrid`
- OCR 测试：图片文字能否被识别并进入分块
- LLM 清洗测试：脏文本是否被重组为更可检索内容
- 大文件测试：请求体限制与上传容量是否生效

## 建议样本
- 纯文本 PDF
- 扫描件 PDF
- 含图表和表格的 PDF
- 含重复页眉页脚的长文档

## 通过标准
- 不同模式下导入过程可完成且返回结构一致
- 至少一种复杂 PDF 在 gd4 中问答质量明显提升
- 缺少某类增强配置时，系统能降级而不是直接崩溃

## 重点观察
- LLM 清洗耗时
- OCR 导入耗时
- 视觉模式的成本与准确率是否匹配
