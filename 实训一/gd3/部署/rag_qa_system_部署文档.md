# gd3 rag_qa_system 部署文档

## 部署定位
gd3 进入“导入质量优化”阶段，引入 PDF 页眉、页脚、重复行清洗参数，适合处理版式噪音较多的文档。

## 新增部署项
- `PDF_HEADER_RATIO`
- `PDF_FOOTER_RATIO`
- `PDF_REPEATED_LINE_THRESHOLD`
- `MIN_CONTEXT_SCORE`

## 推荐部署流程
1. 完成数据库、缓存、向量库与模型配置
2. 针对目标 PDF 类型先设置一组保守的清洗参数
3. 导入 2 到 3 份版式不同的 PDF 做样本验证
4. 检查分块结果后再批量导入
5. 启动服务并验证问答结果

## 部署验收
- 页眉页脚不再大量出现在切块文本中
- 重复页码、重复栏目名明显减少
- 问答结果对正文内容的依赖更强

## 风险提示
- 清洗比例过大可能误删正文
- 清洗比例过小则无法体现版本收益
- 该版本仍以规则解析为主，对扫描件支持有限
