# gd1 rag_qa_system 优化文档

## 当前短板
gd1 已具备可运行性，但稳定性和导入质量仍偏基础。

## 优先优化项
- 增加服务启动前置检查，提前校验 MySQL、Redis、Milvus
- 为 embedding 模型增加预热步骤，缩短首次问答时延
- 为导入链路补充更明确的进度日志
- 在回答前增加最低上下文质量判断，避免无依据回答
- 增强 PDF 清洗，减少页眉页脚和噪音文本进入向量库

## 观测指标
- 服务启动耗时
- 首问耗时与重复提问耗时
- 单份 PDF 的分块数量
- 无答案或低质量答案占比

## 近期建议
gd1 适合作为基线版本保留，后续优化应该围绕“结果质量”和“异常可观测性”两条线推进。
